# Frontend contributors

`src/main.tsx` mounts `app/App.tsx`, which selects scan screens and connects workflow actions. Put scan-specific screens in `features/scans/screens/` (`NewScanScreen.tsx`), report sections in `features/scans/components/report/` (`FixPlanSection.tsx`), scan API calls in `features/scans/api/scan-api.ts`, and scan workflow hooks in `features/scans/hooks/` (`useScanController.ts`). Feature formatting and selection live in `features/scans/utils/`. Name components in PascalCase and hooks `use` + responsibility; use descriptive kebab-case for other modules.

`api/http-client.ts` handles generic HTTP transport. `features/scans/types/scan-contracts.ts` derives wire shapes from server producers using type-only references and retains overlays for older stored reports. Browser runtime code must not import backend database, Node, configuration or queue modules. Shared `components/ui/` and `hooks/` must not import scan features; `components/ui/index.ts` exports the actual primitives and Base UI Tabs, Accordion, Progress, Toggle, and ToggleGroup. Layout belongs in `components/layout/`. `features/scans/components/ScanRepositoryIdentity` shares repository/ref/commit presentation between progress and report screens. Styling lives in `styles/`; follow [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) for approved tokens and accessibility.

Reuse the styled controls first and compose Base UI primitives for interaction behavior rather than rebuilding it in screens. A custom presentation component should have a clear owner and purpose: shared brand marks and generic controls in shared UI, scan-specific presentation in the scan feature. Badges, inline notices, command blocks, and the severity chart stay app-owned; they have no direct Base UI replacement. Do not add generic wrappers for ordinary layout markup.

From the repository root run `npm run typecheck` and `npm run build` for source checks; `npm test` covers report selectors and formatting, and `npm run test:web` runs the Playwright browser contracts against its own Vite server. Build before `npm run test:integration` because its static-route contracts serve `web/dist`.
